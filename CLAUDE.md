# CLAUDE.md

Las reglas de este repo viven en **`AGENTS.md`**, que es el mismo archivo que
usan los otros agentes. Este es solo el puntero para que Claude Code lo cargue.

**Leé `AGENTS.md` ahora.**

Y antes de escribir código, según lo que vayas a hacer:

- llamar al API → `specs/CONTRATO-API.md`
- agregar una dependencia → `specs/STACK.md`
- saber qué toca hacer → `specs/TICKETS.md` + `specs/BITACORA.md`
- pantalla o llamada nueva → `specs/CHECKLIST-PANTALLA-NUEVA.md`

Al terminar un tramo de trabajo, actualizá `specs/BITACORA.md`.

No dupliques acá el contenido de esos archivos: si algo cambia, se edita el
archivo original, nunca este.
